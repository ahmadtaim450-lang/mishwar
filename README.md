# مشوار 🚗
### رفيقك بالطريق بين المدن السورية

**مشوار** تطبيق سوري لمشاركة الرحلات بين المدن، على فكرة BlaBlaCar، بس مصمّم للواقع السوري وبطابع بيحترم قيمنا.
**بس السائقين الموثّقين بينشروا رحلات:** كل سائق بيقدّم أوراقو (هوية، شهادة سواقة، لا حكم عليه، أوراق السيارة)، وبيعمل مقابلة وفحص سيارة بنقطة مشوار قبل ما يتفعّل. الراكب بيحجز مقعد بأمان، وبيتأكد من السائق برمز رحلة ورقم السيارة.

---

## 📥 تنزيل التطبيق

كل ما ينرفع تعديل على الفرع `main`، بيتبنى ملف APK لحالو.

1. فوت على قسم **[Releases](../../releases)**.
2. نزّل الملف اللي اسمو فيه **`arm64-v8a`**، لأنو بيناسب معظم الموبايلات.
3. افتحو على الموبايل وسمحلو بالتثبيت.

## 💡 الفكرة

| المشكلة | الحل |
|---|---|
| السفر بين المدن غالي، والسرافيس والبولمانات مواعيدها محدودة | سيارات خاصة رايحة أصلاً، وفيها مقاعد فاضية |
| السائق بيسافر لحالو وبيدفع البنزين كلو | بيقسّم المصروف مع ركاب على نفس طريقو |
| الثقة بالغريب صعبة | شبكة سائقين موثّقين بمقابلة وفحص، رمز رحلة، تقييمات، ورحلات نسائية وعائلية |

**الشعار:** سافر بين المدن براحة وأمان.

## 🤝 مبادئ التطبيق

- **ما في اختلاط:**
  - **رحلات رجال:** سائق رجل وركاب رجال.
  - **رحلات نسائية:** سائقة امرأة موثّقة وراكبات فقط.
  - **رحلات عائلية:** عائلة مسافرة مع بعض، ووجود المرأة مع سائق رجل بيكون فقط ضمن عائلتها.
- **لكل السوريين:** التطبيق محايد وما بيميّز بين حدا، ومحتشم بالصور. تفضيلات الرحلة: أغاني أو بلا أغاني، ووقفات استراحة.
- **عدل بالسعر:** السعر لتقسيم المصروف وليس للربح، والتطبيق بيقترح سعر عادل حسب المسافة والبنزين.
- **الخصوصية:** رقم الموبايل ما بيظهر إلا بعد قبول الحجز، وصورة الهوية للتوثيق فقط.

## ✨ الميزات (النسخة الحالية: الواجهات)

### الدخول والتسجيل
- شاشة بداية فيها **خريطة سوريا الحقيقية** (من بيانات الحدود الجغرافية مع الجولان)، وسيارة بتمشي بين المدن.
- 4 شاشات تعريف، والدخول برقم الموبايل ورمز تحقق.
- تسجيل على 5 خطوات: الاسم، الجنس، تفضيل الرحلات (رجال / نسائية / عائلية)، الصورة، والأذونات.

### البحث والحجز
- بحث من / إلى، مع التاريخ وعدد الركاب، وتبديل الاتجاه.
- وجهات شائعة بصور المدن السورية.
- نتائج فيها حالة تحميل، وترتيب، وفلاتر (نوع الرحلة، حجز فوري).
- تفاصيل الرحلة، المسار والوقفات عالخريطة، ملف السائق، والتقييمات.
- مراجعة الحجز، **الحجز العائلي** (إضافة أفراد العائلة)، ورسالة للسائق.
- شاشة تأكيد بأنيميشن احتفال.
- قسم خاص للرحلات النسائية والعائلية.
- "ما في نتائج" مع تفعيل تنبيه.

### الانضمام كسائق موثّق
- طلب بـ5 خطوات: المعلومات، تصوير الأوراق، السيارة وصورها، موعد المقابلة، والتعهد بقواعد مشوار.
- شاشة متابعة الطلب: المراجعة، المقابلة، التفعيل.
- صفحة "كيف منوثّق السائقين" للركاب.

### نشر رحلة (للسائق الموثّق بس)
- 8 خطوات: الانطلاق، الوجهة، الوقفات، التاريخ والوقت، المقاعد، **السعر المقترح**، نوع الحجز ونوع الرحلة، والتفضيلات.
- شاشة نجاح، ونشر رحلة الرجعة.

### رحلاتي
- تبويب كراكب وتبويب كسائق، وقبول ورفض طلبات الحجز.
- تذكرة الرحلة مع تذكير **قبل ما تطلع** (الموعد، المكان، المبلغ).
- **التتبّع المباشر** عالخريطة، وزر الطوارئ، ومشاركة الرحلة مع الأهل.
- "وصلت بالسلامة"، التقييم بالنجوم، وإلغاء الحجز.

### الرسائل والحساب والأمان
- صندوق الرسائل، محادثة فيها ردود سريعة، والإشعارات.
- الملف الشخصي، التعديل، تفضيلات السفر، السيارات، وسجل الرحلات.
- توثيق الهوية، مركز الأمان، **زر SOS**، والبلاغات.
- الإعدادات، سياسة الخصوصية، الشروط، المساعدة، دعوة الأصدقاء، و"مشوار بلس".

## 🗺️ خارطة الطريق

### المرحلة 1: الواجهات ✅
تطبيق Flutter كامل بالواجهات والأنيميشن وبيانات تجريبية.

### المرحلة 2: الباكند
- [ ] Supabase: قاعدة بيانات، تسجيل دخول برمز SMS، وتخزين الصور.
- [ ] جداول: `users`, `vehicles`, `trips`, `trip_stops`, `bookings`, `booking_members`, `reviews`, `messages`, `alerts`, `reports`.
- [ ] قواعد أمان (RLS) بتطبّق فصل الرحلات حسب النوع على مستوى قاعدة البيانات.
- [ ] محادثة لحظية (Realtime).
- [ ] إشعارات (Firebase Cloud Messaging).

### المرحلة 3: الخرائط والتتبّع
- [ ] خرائط حقيقية (OpenStreetMap)، واختيار نقطة اللقاء عالخريطة.
- [ ] تتبّع مباشر للرحلة، ورابط مشاركة للأهل بدون تطبيق.
- [ ] حساب المسافة والسعر المقترح تلقائياً.

### المرحلة 4: الثقة والأمان
- [ ] توثيق الهوية والسيلفي، ومراجعة من لوحة الإدارة.
- [ ] لوحة إدارة (ويب): الأعضاء، البلاغات، التوثيق، والإحصائيات.
- [ ] نظام إنذارات لإلغاء الرحلات المتكرر.

### المرحلة 5: الدخل 💰
- **مشوار بلس** للسائقين: ظهور بأول النتائج، رحلات متكررة، شارة مميّز، وتقارير.
- **إبراز الرحلة** مقابل مبلغ صغير.
- **عمولة رمزية** على الحجز، بعد ما يكبر المجتمع.
- **رحلات الشركات:** نقل موظفين بين المدن.
- **طرود صغيرة:** توصيل أمانات مع المسافرين.

### المرحلة 6: التوسّع
- [ ] رحلات داخل المدينة (دوام، جامعة).
- [ ] حجز مقاعد بالسرافيس والبولمانات.
- [ ] نسخة iOS.
- [ ] الإنكليزية والكردية.

## 🛠️ البنية التقنية

```
lib/
├── main.dart              # التطبيق، اللغة العربية والاتجاه من اليمين
├── core/theme.dart        # الألوان والخطوط والثيم
├── data/
│   ├── mock.dart          # بيانات تجريبية (رحلات، مدن، تقييمات)
│   └── syria_map.dart     # حدود سوريا الحقيقية وإحداثيات المدن
├── widgets/common.dart    # أزرار، بطاقات، أنيميشن (Enter, Floaty, Press)...
└── screens/
    ├── splash.dart        # الخريطة والسيارة المتحركة
    ├── onboarding.dart, auth.dart, shell.dart, home.dart
    ├── search.dart, trip.dart, publish.dart, my_trips.dart
    └── messages.dart, profile.dart
```

- **Flutter** بدون مكتبات خارجية، كل الأنيميشن مكتوب بالكود.
- **GitHub Actions** (`.github/workflows/build-apk.yml`) بيعمل التالي:
  1. بينزّل الخط والرسومات (`assets/manifest.txt`).
  2. بيبني الـ APK.
  3. بينشرو بـ Releases.
